# Data licenses

This file lists the datasets and models this playbook uses, where they come from, and their licenses. The code in this repository is MIT-licensed. That license does not cover third-party data or models; each one keeps its own license, listed below.

## Datasets

| Dataset | Source | License | In this repo |
|---|---|---|---|
| Future Factories analog dataset (sensor telemetry at 10 Hz) | [Kaggle: ramyharik/ff-2023-12-12-analog-dataset](https://www.kaggle.com/datasets/ramyharik/ff-2023-12-12-analog-dataset), Future Factories lab, University of South Carolina | [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) | No. Downloaded by `make data` (`python download_data.py`) into `data/analog/`. Needs a Kaggle API token |
| Future Factories multimodal dataset (selected batches, and the images of every Nth reading) | Kaggle: `ramyharik/ff-2023-12-12-multi-modal-dataset-16`, `-26`, `-36`, `-46`, `-56` and `-66` (for example [part 16](https://www.kaggle.com/datasets/ramyharik/ff-2023-12-12-multi-modal-dataset-16)) | [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) | No. Downloaded by `make data` into `data/multimodal/`. The default download, with the analog set, is about 830 MB. `download_data.py` writes the source and license to `data/SOURCE.json` |
| Synthetic fixture and experiment data | Generated by `tests/fixture.py` and the `experiments/` scripts | MIT (this repository) | No. Written at run time by `make run`, `make smoke` and the `make try-*` targets |

## Models

| Model | Source | License | How it's used |
|---|---|---|---|
| Gemini 2.5 Flash-Lite (`gemini-2.5-flash-lite`) | Google Vertex AI, hosted | Hosted service; no weights are downloaded. Use is governed by Google Cloud's terms | Writes the action plan in the cloud version (`services/ai_planner/`, deployed by `python deploy.py`). The local mode uses rules instead and does not call it |
| An OpenAI-compatible LLM (optional) | Whatever `LLM_BASE_URL` and `LLM_MODEL` point to; no default | Depends on the model you choose | Optional planner in the local mode (`resolve/planner.py`). Not used unless both variables are set |
